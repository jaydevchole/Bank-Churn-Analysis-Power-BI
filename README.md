# Bank Churn Analysis – Power BI

Power BI dashboard for analyzing bank customer churn using demographic and financial metrics.

## 📊 Key Metrics
- Total Customers
- Churned Customers
- Churn Rate %
- Active Customers

## 🔍 Analysis Includes
- Churn by Geography
- Churn by Gender
- Churn by Age Group
- Churn Rate by Credit Score Category
- Impact of Credit Card & Active Membership

## 🎛 Interactive Features
- Gender slicer
- Geography slicer
- Dynamic KPIs
- Drill-down enabled visuals

## 🛠 Tools Used
- Power BI
- DAX
- Power Query
- Data Visualization
